## 🎛️ About
A small retro-styled audio player written in Python.
CRT amber theme + cassette theme, tape-position scrubber, playlist & favorites.

## ✨ Features
- Amber CRT and Cassette themes
- Volume knob, Tape Position scrubber
- Playlist & Favorites (saved in `playlist.json`)
- Hotkeys: `Space` play/pause, `O` open, `S` stop, `L` playlist, `F` favorite, `N` next
- 100% local — no hosting, no telemetry
